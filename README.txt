WEBSITE UTS SAINS DATA — GITHUB PAGES

Isi:
- index.html: halaman statis siap dipublikasikan di GitHub Pages
- assets/: CSS dan JavaScript pendukung tampilan
- dataset_mahasiswa.csv: dataset pendukung

Cara upload:
1. Buat repository GitHub baru.
2. Upload isi folder ini (index.html, assets/, dan dataset_mahasiswa.csv) ke root repository.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu deployment selesai dan buka URL GitHub Pages yang ditampilkan.

Catatan:
GitHub Pages hanya menjalankan file statis HTML/CSS/JavaScript, bukan PHP.
Halaman ini adalah hasil render statis dari halaman PHP, sehingga contoh output ditampilkan di halaman.
Kode praktikum PHP yang ditampilkan tetap berupa materi; untuk menjalankan PHP diperlukan server PHP seperti XAMPP.

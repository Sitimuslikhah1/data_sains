WEBSITE INI MENAMPILKAN:
- Identitas mahasiswa

MENJALANKAN DI XAMPP:
1. Ekstrak folder website_uts_sains_data ke C:\xampp\htdocs\
2. Jalankan Apache.
3. Buka http://localhost/website_uts_sains_data/

UPLOAD KE HOSTING:
1. Pilih hosting yang mendukung PHP.
2. Buka File Manager hosting, lalu masuk ke public_html (atau folder web root hosting).
3. Unggah ZIP dan ekstrak di folder web root. Pastikan index.php berada langsung di root yang menjadi alamat website.
4. Jika ingin domain utama langsung membuka tugas ini, pastikan tidak ada index.html bawaan yang lebih diprioritaskan.
5. Buka domain dan cek seluruh bagian, kode, dan tampilan mobile.
6. Jika hosting meminta versi PHP, gunakan PHP 8.0+ bila tersedia.
